# Aprendiendo Git & Github
- Estos son los pasos para iniciar con Git
## Paso 1
- Inicializar el nuevo repositorio
```
git init
```
- Directorio de Trabajo donde se escribe el código.
## Paso 2
- Enviar los nuevos archivos o archivos modificados al área de preparación.
```
git add index.html
git add .
```
- El área de preparación es donde se preparan los cambios.

## Paso 3
- Registrar una descripción del cambio realizado.
```
git commit -m "Proyecto Base"
```

# Github

git remote add origin https://github.com/HidalgoSanchezAC/url_repositorio_remoto.git
